🎵 Política de Privacidade — CifraFácil

Última atualização: Abril 2026

Resumo

O CifraFácil é um aplicativo de cifras musicais que funciona de forma local no seu dispositivo. Não coletamos, armazenamos ou compartilhamos nenhum dado pessoal.

Dados coletados

Nenhum. O CifraFácil:

  • Não exige cadastro ou login
  • Não coleta nome, email, telefone ou qualquer informação pessoal
  • Não rastreia sua localização
  • Não utiliza cookies de rastreamento
  • Não envia dados para servidores próprios
  • Não integra com redes sociais

Dados armazenados no dispositivo

O app armazena localmente no seu dispositivo (e somente nele):

  • Histórico de buscas recentes (últimas 10 buscas)
  • Cache de cifras visualizadas (para acesso mais rápido)
  • PDFs de cifras que você escolheu salvar

Esses dados ficam exclusivamente no seu dispositivo e não são transmitidos para nenhum servidor. Ao desinstalar o app, todos os dados são removidos automaticamente.

Conexão com a internet

O app utiliza conexão com a internet exclusivamente para buscar cifras musicais em fontes públicas da web. Nenhum dado do usuário é enviado nessas requisições.

Serviços de terceiros

O app não utiliza serviços de analytics, publicidade ou rastreamento de terceiros.

Crianças

O app não coleta dados de nenhum usuário, incluindo menores de idade, e é adequado para todas as idades.

Alterações

Eventuais alterações nesta política serão refletidas nesta página com a data de atualização.

Contato

Dúvidas sobre esta política podem ser enviadas para o repositório do projeto no GitHub.
